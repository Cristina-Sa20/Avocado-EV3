# Robot 3D Model

This directory contains the 3D model of the robot designed in LEGO Studio 2.0.

##  File Information & Downloads

**Format:** `.io` (BrickLink Studio native format)
**Software Required:** [BrickLink Studio 2.0](https://www.bricklink.com/v3/studio/download.page) (Free download)

##  Model Details

The provided `.io` file includes the complete mechanical assembly of the robot. It serves as a visual and functional guide to understand the physical architecture before assembly or reproduction.

**Key features included in the model:**
* **Chassis & Structure:** Overall frame geometry and component placement.
* **Drive & Steering Mechanisms:** Detailed alignment of motors, gears, and steering linkage.
* **Sensor Integration:** Spatial positioning for ultrasonic sensors, color sensors, and camera units.


##  How to Use

1. **Download & Install:** Download and install [Studio 2.0](https://www.bricklink.com/v3/studio/download.page) on your computer.
2. **Open File:** Open Studio 2.0, go to `File > Open`, and select the `.io` model from this directory.
3. **Explore & Modify:**
   * Inspect individual sub-assemblies.
   * Generate step-by-step building instructions (`Instruction Maker`).
   * Export rendering images or modify the mechanical structure for future iterations.
